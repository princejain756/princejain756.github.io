open source

I ship devtools CLIs on npm and fix things upstream where I use them.

  • agent-trials - run claude, codex and gemini agents against the same task suite in throwaway repo copies; verifies by rerunning each agent's own verify scripts
  • ctxvitals - token cost of your MCP servers, skills and rules before you type a word; grades A-F
  • mcp-bouncer - policy proxy for stdio MCP servers: allowlists, SSRF and path-traversal blocking, JSONL audit
  • slopsieve - reviews diffs and PRs for AI-slop signals (weakened tests, debug leftovers, trivial deps)
  • ruleherd - audits agent instruction files for contradictions and dead references

Upstream: merged fixes in cockroachdb/pebble (#842, #843 - one bug open since 2021), lancedb (#4584, #4586), windmill (#11863, #11494). Open work in vercel/ai, starlette, axios, sqlglot. 1,107 contributions in the last year.
